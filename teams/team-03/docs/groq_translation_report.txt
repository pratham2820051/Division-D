PROVIDER SELECTION LOGIC
================================================================================

TRANSLATION_PROVIDER=mock
  -> MockTranslationProvider

TRANSLATION_PROVIDER=groq
  -> GroqTranslationProvider (runtime fallback: MockTranslationProvider)

TRANSLATION_PROVIDER=libretranslate
  -> LibreTranslateProvider (runtime fallback: MockTranslationProvider)

TRANSLATION_PROVIDER=auto
  -> GroqTranslationProvider       if GROQ_API_KEY is set
  -> LibreTranslateProvider         else if LIBRETRANSLATE_URL is set
  -> MockTranslationProvider        else

Restart uvicorn after changing .env — translation_service is a module singleton.

================================================================================
GROQ PROVIDER DETAILS
================================================================================

Class: GroqTranslationProvider
API:   Groq chat.completions (AsyncGroq)
Model: settings.groq_model (default: llama-3.3-70b-versatile)
Key:   settings.groq_api_key

Supported language pairs (bidirectional):
  English (en) <-> Kannada (kn)
  English (en) <-> Hindi (hi)
  English (en) <-> Telugu (te)
  English (en) <-> Tamil (ta)
  English (en) <-> Urdu (ur)

Malayalam (ml) and other codes fall back to MockTranslationProvider.

Veterinary terminology preservation:
  System prompt instructs the model to preserve disease names (Mastitis, FMD,
  PPR), symptoms, animal species, anatomical terms, acronyms, and formatting.
  Temperature defaults to settings.groq_temperature (0.3) for stable output.

DEMO VERIFICATION
================================================================================

1. Set GROQ_API_KEY in backend/.env
2. Set TRANSLATION_PROVIDER=auto (or groq)
3. Restart uvicorn
4. POST /api/v1/translation/translate
     {"text": "Possible disease: Mastitis. Severity: Urgent.", "target_language": "kn"}
5. Expect Kannada output WITHOUT mock prefix "[ಕನ್ನಡ]"
6. Chat: set language to kn, send message — assistant blocks should localize via Groq

================================================================================
KNOWN LIMITATIONS
================================================================================

- Groq requires network access and valid API key; quota/rate limits apply.
- Long assistant blocks may hit groq_max_tokens (default 1024); increase if needed.
- Malayalam (ml) is not supported by Groq provider; uses mock fallback.
- translation_service singleton: .env changes require server restart.
