Missing configuration issues
------------------------------
1. .env.example drift
   - Contains TWILIO_* variables with no Settings fields.
   - Previously contained a literal GROQ_API_KEY value — secrets must not live
     in tracked example files; use empty placeholder only.

2. Reserved settings not consumed at runtime
   APP_HOST, APP_PORT, APP_ENV, DATABASE_URL, CHROMA_*, EMBEDDING_MODEL,
   DEFAULT_LANGUAGE, SUPPORTED_LANGUAGES, SMS_PROVIDER, WHATSAPP_ENABLED,
   SESSION_TTL_HOURS, ENABLE_VOICE, ENABLE_RAG, ENABLE_ALERTS are defined but
   not yet read by application code (except where noted above).

3. Translation provider
   translation_service.py imports settings but always uses MockTranslationProvider;
   no TRANSLATION_PROVIDER env var exists yet.

4. CORS_ORIGINS list parsing
   Single-origin value `http://localhost:3000` works in practice with current
   pydantic-settings defaults. For multiple origins use JSON, e.g.:
   CORS_ORIGINS=["http://localhost:3000","http://127.0.0.1:3000"]

5. Uvicorn not auto-configured
   APP_HOST / APP_PORT are not passed by main.py; start server explicitly:
   cd backend && uvicorn main:app --reload --host 0.0.0.0 --port 8000
