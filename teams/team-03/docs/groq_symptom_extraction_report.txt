PashuMitra AI — Groq Symptom Extraction Report
==============================================
Generated: 2026-05-30

Overview
--------
Symptom extraction now supports an optional Groq (Llama) backend while keeping
the existing rule-based extractor as the default and as a runtime fallback.

Architecture
------------
Farmer message
    │
    ▼
SymptomExtractionService.extract(message)
    │
    ├── USE_GROQ_EXTRACTION=false (default)
    │       └── RuleBasedSymptomExtractor
    │
    └── USE_GROQ_EXTRACTION=true
            └── GroqSymptomExtractor
                    ├── GroqClient → Groq API (llama-3.3-70b-versatile)
                    │       └── JSON: { animal_type, symptoms[] }
                    └── on any failure → RuleBasedSymptomExtractor (fallback)

Public API contracts are unchanged:
- SymptomExtractionResult
- SymptomExtractionService
- SymptomExtractor protocol

Environment variables
---------------------
Required when USE_GROQ_EXTRACTION=true:

  GROQ_API_KEY=gsk_...                    # Groq API key (required for Groq mode)
  USE_GROQ_EXTRACTION=true                # Enable Groq extractor

Optional (existing Groq settings):

  GROQ_MODEL=llama-3.3-70b-versatile      # Default Llama model on Groq
  GROQ_MAX_TOKENS=1024
  GROQ_TEMPERATURE=0.3                    # Capped at 0.2 during extraction

When USE_GROQ_EXTRACTION=false (default), no Groq key is needed.

   Groq JSON:

     "animal_type": "cattle",

   SymptomExtractionResult(animal_type=cattle, symptoms=["fever", "drooling"])

3) Hindi input

Canonical symptom labels
------------------------
Groq is prompted to return labels from the rule-based dictionary, e.g.:
- high fever, fever, drooling, reduced appetite
- blisters on tongue and gums, swollen painful udder quarter
- lameness and reluctance to walk, nasal discharge, reduced milk yield
- … (full list in groq_symptom_extractor.CANONICAL_SYMPTOM_LABELS)

Post-processing maps common KB/LLM variants (e.g. "loss of appetite" →
"reduced appetite") and applies the same suppression rules as the rule engine
(e.g. "high fever" suppresses plain "fever").
